# V2 定向训练与评测摘要

## 数据与训练边界

- 基座模型：`google/gemma-3-1b-it`
- 原始训练样本：1,968
- V2 训练记录：2,724
- 构建方式：只复制训练集内满足指定难例条件的样本，不修改原标签
- 定向切片：非工具边界 300、条件修正 27、多参数调用 229、长状态 200
- 隔离检查：validation、test、challenge 的 `sample_id` 均未进入训练
- 训练方式：4bit NF4 QLoRA，1.5 epoch，学习率 `1e-4`
- 评测方式：固定 Prompt、4bit 推理、贪心解码

数据构建由 `scripts/build_v2_curriculum.py` 完成，完整参数和分布见 `data/tool_use/train_v2_manifest.json`。

## 结论与边界

第二轮定向训练显著改善了工具选择、参数局部正确性和无需工具时的停止判断，但参数完全匹配率仍为 42.61%，说明复杂参数对象的完整生成仍是主要短板。Challenge 是项目内难例切片，不是 BFCL 官方成绩；逐样本原始预测和模型 Adapter 不提交到 Git。
